# 📍 Hangout Dinajpur — Travel Guide & District Tracker

An interactive, mobile-first travel guide and district tracker web application for exploring historical landmarks, nature spots, and scenic locations across all 13 upazilas of Dinajpur District, Bangladesh.

---

## ✨ Features

- **🗺️ Interactive Map Explorer:** Integrated with Leaflet.js and Google Maps tiles, providing accurate GPS coordinates, popups, and instant Google Maps directions for every destination.
- **🏛️ Verified Spots Across All 13 Upazilas:** Features 28 notable tourist spots including Kantaji Temple, Nayabad Mosque, Dinajpur Rajbari, Sukh Sagar, Sitakot Vihara, Ashurar Beel, Hili Land Port, and Barapukuria Coal Mine.
- **🔍 Real-Time Search & Category Filters:** Fast search by place or upazila name, with filter chips for Historical, Nature, Religious, Resort/Park, and Industrial landmarks.
- **📷 Direct Gallery Photo Upload:** Allows travelers to upload their own photos directly from their phone or computer gallery, saved locally in the browser (`localStorage`).
- **🚩 Interactive Dinajpur Vector Map (SVG):** Clickable 13-upazila district map with real-time progress counter, animated milestone progress bar, and traveler badges.
- **📄 Personalized Travel Certificate & Poster:** Customize your name and profile picture, then export your travel progress certificate as **PDF / Print** or high-resolution **PNG image**.
- **📱 100% Mobile-Friendly & Standalone:** Zero-dependency single-file architecture with smooth touch interactions and zero horizontal pixel overflow.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS
- **Maps & Graphics:** Leaflet.js, SVG Vector Polygons
- **Export Engine:** html2canvas, CSS Print Stylesheet
- **Data & Storage:** Browser LocalStorage API

---

## 🚀 How to Run Locally

This project runs standalone with zero installation required:

1. Clone or download the repository:
   ```bash
   git clone https://github.com/your-username/HangoutDinajpur.git
   ```
2. Double-click `index.html` to open it in any modern web browser (Chrome, Edge, Safari, Firefox). No build step or local server is needed.

---

## 🌐 Deploy to GitHub Pages

1. Go to your repository on GitHub.
2. Click **Settings** > **Pages** (in the left sidebar).
3. Under **Build and deployment**:
   - **Source:** Select `Deploy from a branch`
   - **Branch:** Select `main` (or `master`) and folder `/(root)`
   - Click **Save**.
4. Your site will be live within 1–2 minutes at:
   `https://<your-username>.github.io/<repo-name>/`
